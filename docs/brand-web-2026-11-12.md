# Web brand update — 2026-11-12

Applies the supplied **Mezon Brand Resource, release 2026-11-12** to Chat,
Discover and Admin. Desktop, iOS, Android and publication of the complete design
package are outside this Web change.

## Asset sources

All artwork is copied unchanged from the release package. Do not redraw or
recolour the SVG paths. The package README defines a clear space of at least a
quarter of the logo height on every side.

| Repository usage              | Package source                                                          |
| ----------------------------- | ----------------------------------------------------------------------- |
| Shared wordmarks              | `01_Logo/SVG/mezon-logo-on-light.svg`, `mezon-logo-on-dark.svg`         |
| Shared marks                  | `02_Mark/SVG/mezon-mark-on-light.svg`, `mezon-mark-on-dark.svg`         |
| Sidebar, QR and system avatar | `03_AppIcon/Web/icon-192.png`                                           |
| Favicons, touch and PWA icons | `03_AppIcon/Web/`                                                       |
| Safari pinned tab             | `02_Mark/SVG/mezon-mark-black.svg`                                      |
| Browser tile, 150 × 150       | `03_AppIcon/Windows/appx/Square150x150Logo.scale-100.png`               |
| Chat splash, 280 × 52         | `05_Splash/Desktop/splash-logo-on-light.svg`, `splash-logo-on-dark.svg` |
| Social preview, 1200 × 630    | `03_AppIcon/Web/og-image.png`                                           |

React consumers import the named URLs from `@mezon/assets`; the bundler resolves
the deployment base and content hashes. Legacy asset filenames also contain the
new artwork so the existing static copies no longer ship the previous logos.
The historical `mezon-logo-white.svg` alias is the mark **on light**; new code
uses the explicit `mezonMarkOnLight` / `mezonMarkOnDark` exports instead.

Each manifest uses separate `any` and opaque `maskable` images at 192 and 512 px.
Icon URLs resolve relative to the manifest. App identity and routing remain
`/chat/`, `/`, and `/developers/` respectively. Browser metadata uses the release
query `v=20261112` to refresh previously cached icons.

The Chat theme bootstrap is a classic script copied with the static assets, so
it runs before the main application bundle. It prefers `current-theme`, falls
back to Redux's serialized `themeApp`, and treats `light` and `sunrise` as light
appearances, matching `ThemeManager`.

Persisted system references and the default profile avatar use the stable public
URL `https://mezon.ai/chat/assets/brand/app-icon.png?v=20261112`, served by the
Chat build. UI previews use the bundled image. Deploy this asset with the Web
release before expecting the new public URL to work in other clients.

## Verification

-   59 copied assets checked byte for byte against the supplied package.
-   All 12 PWA entries checked against actual PNG dimensions; maskable images have
    no transparency. Apple touch icons are 180 × 180; browser tiles are 150 × 150.
-   ESLint on changed source files: no errors; existing warnings remain.
-   Chromium checks passed for all three apps' favicon/touch/manifest URLs and all
    12 manifest icons. Chat splash screenshots cover light, dark and sunrise at
    280 × 52 px; a 320 px viewport keeps the logo within the screen. Ten bootstrap
    cases cover current/persisted theme precedence, corrupt storage and first use.
-   Screenshots cover the Discover header on both backgrounds, its footer, and
    separate light/dark previews of the shared assets and all browser icons.
    Signed-in Admin screens redirect to login in the isolated browser session, so
    those screenshots and the authenticated Chat flows still need account QA.
-   SHA-256 scans of source and all three bundles found no remaining copies of the
    replaced logo binaries. The old hard-coded logo CDN URLs are absent from the
    generated JavaScript.
-   Production bundles can be generated for all three apps. The standard Nx build
    is currently blocked by the checkout's SDK mismatch: `package.json` requests
    `mezon-js` 2.16.26, `yarn.lock` records 2.16.24, and the installed package is
    2.16.22. TypeScript reports missing `FriendStateUpdated`,
    `Client.onfriendstateupdated` and `AddFriend.accepted` in unchanged chat/friend
    code. Dependency files were not changed by this update.
-   Bundle inspection uses Vite directly for Chat/Discover and
    `nx build admin --skipTypeChecking` for Admin. This checks packaging without
    claiming that the standard build or type check passes.

Before release, synchronize the SDK dependencies and run the normal builds.
Capture the authenticated sidebar, profile/invite QR (including PNG export),
channel settings, and Admin header in both appearances. Check installed PWAs on
the target browsers and update any separately hosted brand download package.
